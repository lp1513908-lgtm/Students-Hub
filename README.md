# 🎓 Students Hub

Students Hub is a MERN Stack based student management web application designed to manage student information and course details in a simple and user-friendly way.

## 🚀 Features

* View all students
* Search students by name
* Filter students by course
* Add new students
* Update student details
* Delete student details
* Display total student count
* Course-wise student management

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/lp1513908-lgtm/Students-Hub.git
```

### 2. Open the project

```bash
cd Students-Hub
```

### 3. Start the Backend

```bash
cd back-end
npm install
node server.js
```

The backend server runs on:

```text
https://students-hub-3.onrender.com
```

### 4. Start the Frontend

Open another terminal:

```bash
cd back-end/front-end/my-app
npm install
npm run dev
```

The frontend will run on the Vite development server.
